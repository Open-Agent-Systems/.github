## 关于我们

**Open Agent Systems（OAS）** 是一个面向 AI 云原生生态的开源组织。我们希望通过开放共建，让模型、智能体、工具和运行环境更容易连接与协作，为开发者构建、交付和运行 AI 系统提供可组合的基础能力。

我们从真实的工程需求出发，逐步完善从开发到运行的工具与基础设施，让开发者把更多精力放在创造价值上。

## 建设方向

| 方向 | 我们希望解决的问题 |
| --- | --- |
| AI 辅助研发 | 将 AI 融入编码、测试、交付与项目协作，改善开发体验。 |
| 智能体与应用 | 支持智能体构建、技能复用、工具集成与流程编排。 |
| 云原生基础能力 | 完善执行环境、部署、资源管理和可观测性。 |
| 生态互通 | 连接独立工具与项目，减少重复建设和集成成本。 |

这些是长期建设方向，已交付能力与验证范围以各项目说明为准。

## 首个项目

**Open Managed Agents（OMA）** 是基于 Claude Code 的自托管工作台，统一管理项目、智能体、技能、会话与任务流程，支持本机执行和 Docker 执行节点。

当前状态：正在准备首次开源发布，公开源码仓库尚未上线。

## 共建原则

- **开放共建**：共享成果，欢迎不同背景的开发者参与。
- **组合优先**：保持清晰边界，让独立能力能够协同工作。
- **开发者友好**：重视易用性、文档和实际开发体验。
- **工程务实**：从真实需求出发，持续完善可验证、可维护的实现。
